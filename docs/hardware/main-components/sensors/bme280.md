# Capteur de pression, humidité et température — BME280

:::info Release
Ce capteur équipe uniquement la **V1c**. Il remplace le [WSEN-PADS](./wsen-pads), le [WSEN-HIDS](./wsen-hids) et l'[APDS-9960](./apds9960) des V1a et V1b (voir [Révisions](../../revisions#capteurs-internes)).
:::

Capteur environnemental combiné qui mesure la pression atmosphérique, l'humidité relative et la température.

## Caractéristiques

| Caractéristique | Détail                                                                                              |
| --------------- | --------------------------------------------------------------------------------------------------- |
| Modèle          | [BME280](https://www.bosch-sensortec.com/en/products/environmental-sensors/humidity-sensors-bme280) |
| Fabricant       | Bosch Sensortec                                                                                     |
| Repère          | U14                                                                                                 |
| Pression        | 300 hPa à 1100 hPa                                                                                  |
| Humidité        | 0 à 100 % RH                                                                                        |
| Température     | -40 °C à 85 °C                                                                                      |
| Interface       | I2C (bus I2C1 interne) / SPI                                                                        |
| Adresse I2C     | 0x76                                                                                                |
| Boîtier         | LGA 8 broches, 2,5 x 2,5 mm                                                                         |
| Datasheet       | [BME280](https://www.bosch-sensortec.com/en/products/environmental-sensors/humidity-sensors-bme280) |

## Câblage

D'après le schéma indice C (feuille FP12, page 13/16) :

| Broche BME280 | Connexion                                  |
| ------------- | ------------------------------------------ |
| SDI           | I2C1_SDA                                   |
| SCK           | I2C1_SCL                                   |
| CSB           | +3V3 par R80 (0 Ω) : sélection du mode I2C |
| SDO           | GND : adresse 0x76                         |
| VDD, VDDIO    | +3V3, découplées par C59 et C60 (100 nF)   |

Le schéma indique « BME280 ou BME680 » : l'empreinte accepte aussi le BME680, qui ajoute un capteur de gaz. La nomenclature de l'indice C prévoit un BME280.
